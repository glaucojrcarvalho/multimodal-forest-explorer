# Contributing

Contributions are welcome when they preserve the project's research and publication standards.

## Requirements

- Keep changes small and reviewable.
- Use only public or explicitly reusable data.
- Document source and reuse basis for external assets.
- Distinguish source measurements, labels, published metrics, and any future model outputs.
- Add citations for research claims.
- Avoid implying institutional endorsement or affiliation.
- Run the production build and typecheck before requesting review.\n- Preserve per-file license notices and the boundaries documented in `LICENSE_SCOPE.md`.

## Pull requests

Explain the problem, rationale, provenance, validation performed, and known limitations.

For analytical features, include a reproducibility note and avoid unsupported scientific claims.
