# Code of conduct

This project expects professional, respectful, evidence-oriented collaboration.

Contributors should:
- discuss ideas and code respectfully;
- give credit to research, data, and prior work;
- respect privacy, licensing, and ecological sensitivity;
- distinguish evidence from interpretation;
- report errors openly and correct them transparently.

Harassment, discriminatory conduct, deliberate research misrepresentation, and knowingly unlicensed redistribution are not acceptable.

Project maintainers may remove contributions or participation that violate these expectations.
