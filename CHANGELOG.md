# Changelog

## 1.0.0 — Stable research prototype

### Real data
- Integrated the FOR-age dataset as the primary real-data source.
- Added three Lillomarka trees with paired ALSHD and MLS browser point clouds.
- Preserved source-derived species, tree-age labels, height, crown measurements, split, and point counts.
- Added local LAS/LAZ inspection without uploading visitor files.

### Geospatial context
- Added Kartverket DTM and DOM hillshade through official Geonorge WMS services.
- Added visible © Kartverket / CC BY 4.0 attribution.
- Kept regional context separate from claims of exact tree co-registration.

### Research and provenance
- Added FOR-age tree-age benchmark and ForestFormer3D research context.
- Added deterministic preprocessing, source manifest, dataset/model license matrix, citation metadata, notices, disclaimer, and ethics policy.
- Added publication gates for real-data integrity and repository/publication policy.

### Product and UX
- Replaced the procedural forest prototype with the real point-cloud laboratory.
- Added specimen/sensor switching, height legend, camera presets, responsive/mobile navigation, and lazy viewer loading.
- Added public-facing research context, reproducibility lineage, and source attribution.
- Added a custom production domain and release-only Vercel deployments.

### Repository
- Removed obsolete synthetic/procedural implementation code.
- Defined MIT application-code licensing with explicit FOR-age OSOML and Kartverket boundaries.
- Classified RGB, satellite, field observations, co-registration, and empirical inference as future research directions rather than unfinished v1 work.
