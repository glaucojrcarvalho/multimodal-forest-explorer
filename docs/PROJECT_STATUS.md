# Project status

Status: **stable v1 scope complete**

Forest Intelligence Explorer has reached the intended scope of the public research prototype.

## Complete

- real FOR-age individual-tree point-cloud visualization;
- three Lillomarka trees with paired ALSHD / MLS acquisitions;
- source-derived tree attributes and provenance;
- browser-local LAS/LAZ inspection;
- Kartverket DTM / DOM regional landscape context;
- published FOR-age and ForestFormer3D research context;
- deterministic preprocessing and release validation;
- licensing, citation, attribution, disclaimer, ethics, and scientific-validation policies;
- responsive desktop/mobile UX and accessible navigation;
- custom production domain and release-only deployment workflow.

## Not part of the stable v1 acceptance scope

The following are research extensions, not unfinished tasks:

- RGB/drone imagery;
- satellite time series;
- field-observation integration;
- exact cross-dataset geospatial co-registration;
- production ML inference;
- multimodal model training/evaluation;
- large-scale remote point-cloud streaming.

If the project is extended later, those items should start as new research questions/issues with their own data, licensing, validation, and publication review.

## Stable release

The next non-prerelease production release is intended to be **v1.0.0**.
