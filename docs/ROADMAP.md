# Roadmap

## Phase 1 — Synthetic prototype
- deterministic 3D forest
- typed modality layers
- provenance model
- public research source log

## Phase 2 — Interactive multimodal explorer
- modality switching
- legends and citations
- uncertainty and provenance in the interface
- accessible mobile experience

## Phase 3 — Public research cases
- project cards based on public sources
- source-level traceability
- clear non-affiliation language

## Phase 4 — Licensed open data
- identify a reusable forest dataset
- document license and preprocessing
- add reproducible import scripts

## Phase 5 — Validated analytical demonstration
- explicit task and baselines
- appropriate evaluation design
- single- versus multimodal comparison
- documented limitations

## Phase 6 — Public release
- accessibility review
- provenance audit
- performance review
- scientific-claim review
